# demos

One small static browser demo per week, built from libraries mp bookmarked on X.

- Each demo lives in `demos/<yyyy-mm-dd>-<lib>/`.
- Static HTML/CSS/JS, or a Vite project (`package.json` with `npm run build` → `dist/`).
- No backend, no secrets.
- Every demo is previewed on GitHub Pages: https://xpat07.github.io/demos/

See [DEMOS.md](DEMOS.md) for the list.
